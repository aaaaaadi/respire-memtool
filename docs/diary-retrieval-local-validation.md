# 日记检索与资料采用：本机交付记录

日期：2026-10-26；提交前复核：2026-10-27。

## 项目边界

- MemTools：保留已有完整正文关键词过滤，增加最多3个、每个360 UTF-16单元的命中窗口、时间/短来源、高亮及原文定位；按 importance 区分主记忆和日记。增加具体上级搜索、记录去向和保存后查看。保存后保留回执，用户手动关闭窗口。
- Respire Codex 插件：独立分支 fix/diary-evidence；区分已确认约定、已验证事实、未验证参考、历史/冲突。候选分数/important/更新时间不能证明可信；日记工具有固定参数与输出预算，不满足主记忆读前写后的门槛。
- RSRS CLI：独立分支 fix/diary-fragments；完整正文 diary --contains、独立日记片段搜索/邻段读取、派生索引与公开 Core SDK 调用。普通 recall 不变。目标片段先分预算，邻段不能挤掉目标。
- 不修改闭源 Core 内部，不改变原日记、同步内容或既有记忆正文。

## 已验证

- MemTools 前端19项通过；Rust 133项通过、1项明确忽略；正式 release 构建成功。
- 浏览器隔离样例：十万字正文尾部命中、高亮与原文滚动；选择具体上级传真实ID；存在祖先时查看保存结果展开目标卡片；快捷日记回执保留，查看只传memoryId不预填正文。
- 本机真实服务只读：516条记录快照中，8291字日记的末尾匹配定位为65字窗口，切片与原文一致。未为验证写入实际记忆。
- 插件 local.5 的43项测试、语法检查与包结构校验通过；合成资料的两项真实模型受控验证通过，覆盖逐条依据/参考/历史标签及未采用场景。用户确认桌面简短提示与采用标签已显示。上述结果不等于日记自动提炼端到端验收。
- RSRS真实Rust源模块隔离验证通过：十万字尾部、Unicode位置、预算、邻段和过期定位。正式编译被缺少匹配Core SDK阻断；隔离验证不代表Core语义调用或Runtime路由通过。
